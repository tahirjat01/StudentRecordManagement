# Demonstration Video Script (about 3–4 minutes)

1. **Introduction (20 seconds):** State your name, roll number, course and project title. Explain that the app uses C++17, Qt 6 Widgets and CSV file handling.
2. **Open the application (20 seconds):** Show the six fields and buttons. Point out that Update and Delete are disabled at startup.
3. **Add a student (40 seconds):** Enter a complete sample record, click Add Record, show the confirmation and table row.
4. **Validation (30 seconds):** Try an empty field, invalid GPA and duplicate Roll Number. Explain the validation messages.
5. **Browse and update (45 seconds):** Click Next Record, show the mode change, edit a field and click Update.
6. **Delete and add mode (35 seconds):** Click Delete, demonstrate confirmation, confirm, then click New / Add Mode.
7. **Persistence and conclusion (30 seconds):** Open students.csv and optionally restart the app to show saved records. Summarize the features.

Before recording, build and run the app, use sample data, capture the actual application (not the conceptual preview), and avoid showing private student information.
